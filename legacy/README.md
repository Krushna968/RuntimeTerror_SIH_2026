# Legacy & Prototype Artifacts

This directory contains experimental prototypes, design mockups, and early iteration assets archived from the active application codebase:

- **`backend_new_home_page/`**:
  - `adsa.tsx`: An experimental React landing hero component originally authored during exploration. Superseded by `client/src/components/OrcaLandingHero.tsx`.

- **`dag_agent_ui/`**:
  - `background.tsx`, `image.png`, `prompt.md`: Design mockups and prompt engineering references created during the conceptualization of the Agent DAG Studio. Superseded by `client/src/components/AgentDAGStudio.tsx`.

- **`frontend_prototypes/`**:
  - `LovableLandingHero.tsx`: Alternative landing page hero component. Kept for historical UI design reference.
